# mxdpppplus

像素风卡牌对战游戏。Godot 4.7.2，横屏（手机/平板），电脑 1920×1080。客户端与服务端在同一个 Godot 工程里：带 `--server` 启动即为权威服务端。

技能表按你给出的 59 张 + 2 张新技能（`新·觉醒中防`、`新·长攻分散`）完整录入，费用/伤害/可被列/连招均使用表内数值。开局 0 运 1 血，第一回合只能出「运」。

## 目录

```
common/            规则引擎、卡表、网络传输（客户端/服务端共用）
client/            客户端（app.gd 为 Autoload；ui/ 为各屏幕）
server/            服务端（账号、好友、房间、权威对局）
assets/art/        程序生成的像素素材（SVG → PNG）
art_src/gen_art.py 素材生成脚本（cairosvg + Pillow）
tests/             无头规则测试
dist/              服务端交付包（打包产物）
```

## 启动

### 客户端（开发）

```bash
godot --path /workspace
```

首屏点「联机模式」自动连接服务器，点「单机模式」直接 1v1 人机。服务器地址由构建时注入的本地私有配置决定，不写入开源仓库。

### 服务端

```bash
godot --headless --path /workspace -- --server --port=7777
```

`run_server.sh` / `run_server.bat` 是对应的一键脚本。服务端只需要 UDP 端口可达；局域网调试时在本地私有配置里指向你的 IP 与端口。

- 账号：客户端读取设备唯一标识（Android/iOS 用系统 ID，桌面用系统信息+本地兜底 ID），SHA-256 后作为账号键。服务端只保存哈希，不保存原始硬件码。
- 数据：`user://mxdpppplus_accounts.json`；可用环境变量 `MXD_DATA_PATH` 指定路径。
- 用户名：2~12 字符，唯一；好友码 6 位数字。

### 服务端交付包（直接发给服务器提供者）

`dist/` 下已生成：

- `mxdpppplus-server-win64.zip`：Windows 服务端（`mxdpppplus_server.exe` + 启动脚本 + 部署说明）
- `mxdpppplus-server-linux.zip`：Linux 服务端（`mxdpppplus_server.x86_64` + 启动脚本 + 部署说明）
- `mxdpppplus-source.zip`：完整源码（不含构建产物），交给需要自己编译/改服务端的人

Windows 解压后双击 `run_server.bat`，Linux 运行 `./run_server.sh`；默认 UDP 7777。详见 `SERVER_README.md`。服务端二进制带 `dedicated_server` 特性，启动即服务端，不需要编辑器。

源码模式启动：

```bash
godot --headless --path . -- --server --port=7777
```

重新导出服务端（需要 4.7.2 导出模板）：

```bash
godot --headless --path . --export-release "LinuxServer" dist/mxdpppplus_server.x86_64
godot --headless --path . --export-release "WindowsServer" dist/mxdpppplus_server.exe
```

## 联机流程

1. 连接服务器 → 自动注册/登录 → 首次设置用户名。
2. 主菜单：单人模式 / 多人联机 / 好友 / 改名 / 退出。
3. 大厅：公开房间列表、房号加入、创建房间；私密房间不在列表，可用房号或邀请进入。
4. 房间：房主可改公开/私密、人数上限、AI 自动补全、出牌限时、友伤、变态模式；可踢人。全员准备后房主开始。
5. 好友：好友码添加，对方同意后生效；可邀请好友。邀请成功时邀请者成为房主（若邀请者原本不是房主，会新建一个自己的房间）。
6. 对局：每回合秘密选牌 + 目标，同时翻开结算；8 人/7 人按座位连续分两队（8→4v4，7→3v4）。

默认值：公开、人数上限 6、不补 AI、出牌限时 10 秒（单人模式，或房间内只有 1 名真人时不限时）、友伤关、变态模式关。

## 规则实现要点

- 伤害用十分之一整数存储（0.1 = 1），避免浮点漂移。
- 同时结算：费用、连招、冷却、运增减照常；伤害相同互相抵消，不同只有高者生效；代码杀优先。
- 挡、吸、运挡、闪、盾、护身符、酒、强化运、觉醒中防等按「可被」列 + 卡牌自身特殊说明实现。
- 盾为存储资源，自动挡致命伤；`盾需2个`的牌（意大利炮、战术核弹）盾不足 2 完全不挡且不消耗；可挡代码杀；保命后保留受击前血量。
- 连招按实际出牌历史判定；被挡/被吸/被无效仍推进；鄙视清空；扭转时空重置。
- 龟派转化、神之龟派翻倍、自杀反制、抢夺究掐、微镖/降龙/降飞被吸等表内特例已实现。
- 新·觉醒中防：1 运，挡「中防可被列」覆盖的技能；除核弹外反弹 `min(伤害×50%, 0.8)`；对比心反弹 -1 运；对鄙视反弹为下回合强制中防。
- 新·长攻分散：3 运、2.4 伤害，可被中防/吸/负运/闪/护身符。被中防→空间分散（目标及左右相邻敌人 -0.5，友方与出招者除外，溅射可被中防/闪）；被吸→时间分散（本回合所有被吸者每回合 -0.4，持续 k 回合，k=吸到的运数；桃/净化可解）。

完整测试：

```bash
godot --headless --path . --script res://tests/test_engine.gd
```

## 设计裁定（技能表未写明处）

以下是为了能完整开局做的实现裁定，均已集中在代码里，后续可按你的口径调整：

- 多人伤害对比按「攻击者→目标」与「目标→攻击者」成对比较；多目标牌逐目标比较。聚伤/飞雷神在比较后重定向伤害。
- 空间分散的「左右」按座位顺序（队伍连续分半），排除出招者及其友方。
- 战术核弹可变费用自动取 `min(4, 当前运)`；葵花宝典的 50% 不作用于它和盾。桃园结义费用=参战人数×1 运；横扫大地费用=存活人数×1 运。
- 吸的默认收益=被吸卡的费用；表内有特例按特例（降龙/降飞 +2、微镖改为使用者 +1、新长攻分散按 3、超级吸×2）。
- 酒复活后运固定为 1；亡灵返乡复活为 1 血、保留运/盾/状态、持续 5 回合；借尸还魂目标直接替死并继承血/盾，费用 6 即公式里的 -6，最终运=你的当前运+目标运。
- 死亡笔记只实现「让目标自杀」分支；「指定另一人对目标用指定技能」分支未实现。
- 超时自动用 AI 选一张合法牌；鄙视导致的下回合空过由服务端自动 pass。
- 同归于尽按本回合造成的伤害总量判定胜队；仍相等则比较回合开始时总血量，再相等判 A 队。
- 龟派在多人模式需要选择一名敌人作为转化对象；两人指定同一人则都无效；1v1 双方同时龟派都无效。
- 单人模式固定 1v1；变态模式下 AI 可在你提交后看到你本回合的牌；AI 之间不共享选择。
- 旧「觉醒中防」按攻击性技能拦截并反弹 0.5；新「觉醒中防」按中防可被列 + 比心/鄙视拦截。
